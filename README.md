Description

Luxury Liverpool is a fictional luxury property website created as a personal web development project. The website showcases a collection of fictional high-end residential properties in Liverpool, featuring a modern design and elegant visual presentation.

This project was developed for practice and to build my front-end web development skills.

All properties, prices and listing information are fictional and for demonstration purposes only.

Technologies Used

HTML

CSS

What I Learned

Building a multi-page website from scratch.

Writing and structuring HTML.

Styling webpages using CSS.

Creating consistent layouts and visual designs across multiple pages.

Working with images, spacing, typography and positioning.

Using Git and GitHub to manage and store a development project.
